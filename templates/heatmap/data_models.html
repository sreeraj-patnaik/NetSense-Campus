API surface

Small, stable endpoints for ingestion, visualization, and configuration.

POST /api/scan/

Ingest scans

Validates block, floor, mode, bounds, and blocked cells before insert.

Payload: block, floor, cell_x, cell_y, mode, signal_strength
GET /api/heatmap/

Read heatmap

Returns aggregates and optional interpolation; auto‑rebuild if empty.

Params: block, floor, mode, service_provider, interpolate
GET /api/config/

Fetch config

Delivers blocks, floor configs, and service provider lists.
