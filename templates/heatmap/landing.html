Project Overview

Every layer is focused on one goal: actionable indoor signal intelligence.

Problem

Dead zones, inconsistent mobile coverage, and weak Wi‑Fi are hard to locate indoors.

Solution

Grid‑based scans aggregated into a live heatmap with confidence and interpolation.

Impact

Faster troubleshooting, smarter router placement, and transparency for users.

Data Model

Block → FloorPlan → Scan → CellAggregate. FloorPlan is the single source of truth.

Aggregation

Median signal per grid cell with scan_count as confidence. Interpolation fills gaps.

API

POST /api/scan, GET /api/heatmap, GET /api/config. Minimal, fast, stable.

Visualization

Blended thermal gradients or contour bands with live min/max scaling.

Quality Guardrails
